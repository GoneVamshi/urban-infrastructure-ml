# Urban Infrastructure Failure Risk

## Project Overview
This project investigates machine learning methods for predicting urban infrastructure failure risk.

## Objectives
- Explore and understand the dataset.
- Clean and prepare the data.
- Build and compare Logistic Regression, Decision Tree, and Neural Network models.
- Evaluate model performance using suitable metrics.
- Identify the most suitable model for predicting infrastructure failure risk.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
